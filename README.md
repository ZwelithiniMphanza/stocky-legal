# Stocky legal webpages

Upload the contents of this folder to the root of your stocky-legal GitHub repository. Include index.html, privacy.html, terms.html, eula.html, styles.css, and .nojekyll. No build command or dependencies are needed.

In repository Settings > Pages, choose Deploy from a branch, main, /(root), and Save. Open the URL GitHub provides and check all three document links. The privacy-policy URL ends with /stocky-legal/privacy.html. Use that public webpage URL in Play Console.

These files are publication copy, not a certification of legal compliance or Google approval. The publisher should review the described practices before uploading. Do not upload your app source, databases, backups, or environment files.
